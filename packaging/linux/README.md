# Debian/Ubuntu package

Build the Flutter Linux release, then package the existing bundle:

```sh
flutter build linux --release
python3 tool/package_deb.py
```

The `.deb` and `SHA256SUMS` are written to `build/packages/`. The package contains
the full Flutter bundle, a `reisub-meeting` command, an application menu entry and
icons. Package version and architecture come from the compiled bundle. System
library dependencies are generated by `dpkg-shlibdeps` on the build machine.

Install from the project directory:

```sh
sudo apt install ./build/packages/reisub-meeting_1.0.0-1_amd64.deb
```

Launch **REISUB Meeting** from the application menu or run `reisub-meeting`.
Enter the address and port of your REISUB Meeting server; the server is not
included in this desktop package.

Packaging requires Python 3, `dpkg-deb`, `dpkg-shlibdeps`, and binutils. Build and
package on the same architecture. Use `--bundle PATH` to package another release
bundle, and `--output-dir PATH` to choose the destination.

The current amd64 build uses Ubuntu 24.04/Zorin OS 18 system libraries, including
`libc6 >= 2.38`, `libglib2.0-0t64 >= 2.79.0` and `libstdc++6 >= 13.1`. It is not an
Ubuntu 22.04 or Debian 12 build. For older distributions, rebuild and package on
that target distribution rather than lowering the declared dependencies.
